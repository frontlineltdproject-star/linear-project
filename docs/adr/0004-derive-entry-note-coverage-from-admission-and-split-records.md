# Derive Entry Note coverage from admission and split records

Accepted on 27 October 2026 during FRO-319 review. An Entry Note records the storage admission it belongs to, and the Orders it covers are worked out from the split records: the owning Order plus children split from it after that admission. We chose this over a separately stored list of covered Orders (the pattern FRO-356 uses for ΑΛΚ registration coverage) because a note can be created after the split it must cover, so a stored list would need back-filling and could drift from the split history; the split records are already the authoritative trace of where admitted collis went. The cost is a lineage query on each lookup and uniqueness checks that must consider covered descendants, not just a direct owner column.
