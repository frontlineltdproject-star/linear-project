## Investigated and rejected defect candidates

- **Repeated same-stay measurement could break fetchMap or alter admitted weight:** rejected for current supported flow. Schema uniquely constrains `(handling_unit_id, warehouse_stay_id, measurement_source)` and makes measurements append-only; stock confirmation cannot run again on IN_STOCK. Later stay measurements do not satisfy the stored admission stay filter. No failing current reproduction established.
- **Backdated confirmation before PO membership could yield zero admitted collis:** rejected as a supported reproduction. The surrounding updateStatus chronology and handling-unit journey/membership checks refuse events before the existing recorded sequence; the isolated resolver alone is not the whole write path.
- **Warehouse capability removal could change a descendant's inherited resolution:** a potential future risk, not a current defect. The current warehouse management mutation found here edits addresses only; no supported capability-removal command was found. No invented direct database mutation was used to establish a product bug.
- **Child invoices wrongly enter an inherited entry:** actual FactsReader/Reads harness excludes them; lookup uses owner identity and saved admission.
- **Statistical VAT sums rounded rows or creates zero total for no invoices:** actual source controls show correct once-on-total and empty semantics.
